# KRITICAL KISS website refresh

A responsive, static website inspired by the neon lightning mockup. The design uses the supplied KRITICAL KISS logo, abstract lightning/glow effects, vinyl-record motifs, CSS-drawn merchandise, and platform links. **No band-member photos are used.**

## Preview locally
1. Extract the ZIP archive.
2. Open `index.html` in a modern browser. No build step or server is required.
3. The design uses Google Fonts when internet access is available and falls back to system fonts offline.

## Files
- `index.html` page content and links
- `styles.css` responsive visual design
- `script.js` mobile navigation behavior
- `assets/kritical-kiss-logo.png` supplied logo
- `assets/design-mockup.png` visual reference for the layout

## Links to check before publishing
The current Apple Podcasts, Spotify, YouTube, TeePublic, Facebook, and Instagram links have been carried over from the supplied site. Confirm they are still the intended destinations before launch. This is a fan podcast site, not an official KISS band website.

## Publish
Upload the contents of this folder to your static website host, keeping the `assets` folder alongside `index.html`.
